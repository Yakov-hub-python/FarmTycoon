# 🌾 FarmTycoon

**FarmTycoon** — idle-ферма в Telegram, где игрок развивает собственное хозяйство: покупает семена, выращивает культуры, собирает урожай, улучшает ферму и соревнуется с другими игроками.

> Проект работает как Telegram-бот на Node.js и Telegraf. Данные игроков хранятся в JSON-файле.

[Открыть репозиторий на GitHub](https://github.com/Yakov-hub-python/FarmTycoon)

## 🎮 Возможности

### Ферма и урожай

- Начальный баланс — **100 монет**, стартовое поле — **8 грядок**.
- **12 обычных культур** с разной стоимостью семян, временем роста и ценой урожая: от пшеницы до ананаса.
- Посадка одной или нескольких культур за раз.
- Сбор урожая с отдельной грядки или сразу со всех готовых грядок.
- Расширение фермы за монеты и через улучшения лаборатории. Максимум — **20 слотов**.
- Дополнительные редкие культуры, которые можно получить из кейсов или игровых событий.

### Мутации и погода

- У урожая есть шанс получить мутацию:
  - обычная — базовая награда;
  - серебряная — множитель **×1,75**;
  - золотая — множитель **×4,5**.
- Для обычного броска указаны базовые шансы: 85% / 12% / 3%. Улучшения лаборатории могут повысить шанс золотой мутации.
- Глобальная погода одинакова для всех игроков и меняется каждые **2 часа**. Есть ясная погода, дождь и засуха; погодные условия влияют на рост культур и экономику сбора.

### Развитие

- **Лаборатория** с четырьмя направлениями:
  - 🧬 Генетика — повышает шанс золотой мутации.
  - 🌾 Селекция — увеличивает вес урожая.
  - ⏱ Агрономия — ускоряет рост культур.
  - 🟫 Земля — увеличивает количество грядок.
- У улучшений есть уровни, стоимость и время ожидания между покупками.
- **Система кейсов** с четырьмя уровнями и разной стоимостью:
  | Кейс | Цена | Особые награды |
  |---|---:|---|
  | 📦 Обычный | 10 000 монет | Монеты, включая редкий крупный выигрыш 50 000 |
  | 🥈 Серебряный | 100 000 монет | VIP на 2 дня (1,5%), редкие семена (0,5%) |
  | 🥇 Золотой | 500 000 монет | VIP на 3 дня (1%), семя Огненного цветка (1%), джекпот 3 500 000 монет (1%) |
  | 💎 Легендарный | 2 000 000 монет | VIP на 7 дней (1,5%), семя Кристального плода (2%), джекпот 20 000 000 монет (1,5%) |
- В серебряном кейсе редкие семена — **Золотой виноград** или **Лунная пшеница**. В золотом и легендарном кейсах находятся отдельные редкие культуры.
- Семена из кейсов автоматически высаживаются на свободную грядку. Если свободных грядок нет, игрок получает компенсацию монетами — **66% от максимальной стоимости** соответствующей культуры.
- Кейсы открываются из игрового меню; отдельная команда для открытия не требуется.
- **Ежедневная награда** с ограничением по времени между получениями.
- **VIP** увеличивает прибыль от сбора урожая на 20%.
- Профили, рекорды, титулы и рейтинги игроков.

### Социальные и сезонные механики

- Реферальная система с персональными ссылками и наградами.
- Промокоды.
- Сезонный ивент **«Праздник урожая»** с отдельной валютой и наградами. В текущей конфигурации дата окончания события — **1 декабря 2026 года**; после этой даты сезонные механики могут стать недоступны.

## 🤖 Команды бота

| Команда | Назначение |
|---|---|
| `/start` | Запустить игру или открыть главное меню |
| `/menu` | Главное меню |
| `/help` | Справка по игре |
| `/farm` | Открыть ферму |
| `/me` | Профиль и рекорды игрока |
| `/top` | Рейтинги игроков |
| `/daily` | Получить ежедневную награду |
| `/promo КОД` | Активировать промокод |
| `/setnick Новый Ник` | Изменить игровой ник |

Лаборатория, кейсы, магазин, титулы, друзья и сезонный магазин открываются через кнопки игрового меню и соответствующих экранов.

### Администрирование

В проекте предусмотрены отдельные административные обработчики: управление администраторами, выдача монет игрокам, рассылка, статистика, удаление игроков, управление промокодами, резервное копирование и восстановление базы. Доступ к административным действиям должен быть ограничен доверенными Telegram ID.

## 🧰 Технологии

- **Node.js 18**
- **Telegraf 4** — Telegram Bot API
- **dotenv** — переменные окружения
- **Axios** — HTTP-запросы
- **JSON** — хранение игровых данных

Бот использует long polling (`getUpdates`) для получения обновлений Telegram и небольшой HTTP-сервер для проверки доступности процесса на хостинге.

## 🚀 Запуск локально

### 1. Требования

- Node.js **18.x**
- npm
- Telegram-бот, созданный через [@BotFather](https://t.me/BotFather)

### 2. Клонирование и установка

```bash
git clone https://github.com/Yakov-hub-python/FarmTycoon.git
cd FarmTycoon
npm install
```

### 3. Настройка окружения

Создай в корне проекта файл `.env` на основе `.env.example`:

```env
BOT_TOKEN=токен_бота_от_BotFather
ADMIN_ID=твой_telegram_id
PORT=8000
DB_PATH=database.json
```

- `BOT_TOKEN` — токен Telegram-бота. Обязательная переменная.
- `ADMIN_ID` — Telegram ID администратора. Нужен, в частности, для отправки автоматических резервных копий.
- `PORT` — порт HTTP-сервера; если не задан, используется `10000`.
- `DB_PATH` — путь к JSON-файлу базы; по умолчанию `database.json`.

**Не публикуй `.env` и не отправляй токен бота в репозиторий.** Если токен случайно стал публичным, отзови его через BotFather и создай новый.

### 4. Запуск

```bash
# Режим разработки с перезапуском при изменении файлов
npm run dev

# Обычный запуск
npm start
```

После запуска бот начнёт получать обновления Telegram. Для одного токена должен работать только **один экземпляр** бота с long polling: параллельный запуск локально и на хостинге может привести к ошибке `409 Conflict: terminated by other getUpdates request`.

## 💾 Хранение данных и резервные копии

Игровые данные хранятся в JSON-файле, путь к которому задаётся через `DB_PATH`. В базе находятся записи игроков, их баланс, грядки, улучшения, статистика, VIP, реферальные данные и другая игровая информация.

Текущая реализация `db.js` предусматривает:

- последовательное выполнение операций чтения и записи через очередь;
- запись во временный файл с последующим переименованием;
- нормализацию пользовательских данных и добавление недостающих полей;
- обработку повреждённого JSON-файла.

### Резервное копирование

- Команда `/backup` отправляет резервную копию администратору.
- Автоматический бэкап запускается после старта и затем выполняется раз в сутки.
- Локальные копии сохраняются в папке `backups`; хранятся последние 7 файлов.
- Для автоматической отправки бэкапа должен быть корректно задан `ADMIN_ID`.

**Важно для хостинга:** JSON-файл и папка `backups` должны находиться на постоянном диске. Если платформа удаляет локальные файлы при перезапуске или новом деплое, игровой прогресс может потеряться. Проверь, что выбранный хостинг поддерживает persistent storage, и периодически проверяй, что бэкапы действительно приходят.
