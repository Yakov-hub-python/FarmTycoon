# 🌾 FarmTycoon — Ферма и Экономика

**FarmTycoon** — это экономическая idle-игра в Telegram. Сажай культуры, собирай урожай, лови редкие мутации, прокачивай лабораторию и открывай кейсы с эксклюзивными семенами.

## ✨ Особенности игры
* 🌱 **13+ видов культур:** от быстрой пшеницы до дорогих ананасов.
* 🌦 **Динамическая погода:** каждые 2 часа меняются условия (дождь ускоряет рост, засуха повышает цены).
* 🧬 **Мутации:** шанс выпадения серебряной (×1.75) или золотой (×4.5) мутации.
* 🧪 **Лаборатория:** 4 ветки прокачки (генетика, селекция, агрономия, земля) с кулдаунами.
* 📦 **Кейсы:** 4 уровня редкости. Шанс выбить особые семена, VIP-статус или крупный джекпот.
* 🔥 **Стрики:** ежедневный вход дает прогрессивную награду (до 7-го дня).
* 🔔 **Напоминания:** бот сам пингует, когда урожай готов к сбору.

## 🛠 Технологический стек
* **Платформа:** Node.js
* **Библиотека:** Telegraf (v4)
* **База данных:** Локальный JSON-файл (с атомарной записью и мьютексом).

## 🚀 Установка и запуск
1. Клонируйте репозиторий: `git clone https://github.com/Yakov-hub-python/FarmTycoon.git`
2. Перейдите в папку: `cd FarmTycoon`
3. Установите зависимости: `npm install`
4. Создайте файл `.env` в корне проекта и заполните его:
   BOT_TOKEN=ваш_токен_от_BotFather
   ADMIN_ID=ваш_telegram_id
   DB_PATH=database.json
5. Запустите бота: `npm start`
