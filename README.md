# 🌾 FarmTycoon

**FarmTycoon** — idle-ферма в Telegram, в которой игрок выращивает культуры, собирает урожай, получает монеты и постепенно расширяет своё поле.

Основной игровой цикл прост: **посадить → дождаться созревания → собрать урожай → получить награду → развивать ферму**. На результат сбора влияют вес урожая и случайная мутация.

## 🎮 Возможности

- Регистрация игрока при первом запуске бота.
- Персональная ферма с несколькими слотами для посадки.
- Четыре вида культур с разным временем роста, стоимостью семян и параметрами урожая.
- Случайный вес собранного урожая.
- Система мутаций с разной редкостью и множителями награды.
- Сбор урожая по одному слоту или сразу со всех готовых слотов.
- Покупка дополнительных слотов.
- Ежедневная награда.
- Изменение игрового ника.
- Публичные рейтинги игроков.
- Статистика лучшего сбора.
- Административные команды для управления балансом и базой данных.
- Резервное копирование и восстановление базы через Telegram.

## 🌱 Игровой процесс

### Культуры

В игре доступны четыре культуры:

| Культура | Время роста | Цена семени | Вес урожая | Цена за кг |
|---|---:|---:|---:|---:|
| 🌾 Пшеница | 15 секунд | 100 | 5–15 кг | 12 монет |
| 🥕 Морковь | 1 минута 30 секунд | 500 | 25–75 кг | 12 монет |
| 🎃 Тыква | 7 минут 30 секунд | 3 000 | 30–90 кг | 60 монет |
| 🍉 Арбуз | 30 минут | 20 000 | 1 500–4 500 кг | 8 монет |

После посадки растение занимает слот до момента сбора. Время созревания рассчитывается по времени посадки, поэтому урожай продолжает расти, даже когда игрок не находится в боте.

### Вес и мутации

При сборе для урожая случайным образом определяется вес в диапазоне, заданном для соответствующей культуры.

Затем выбирается мутация:

| Мутация | Вероятность | Множитель награды |
|---|---:|---:|
| Обычная | 85% | ×1 |
| ✨ Серебряная | 12% | ×2 |
| 🌟 Золотая | 3% | ×6 |

Награда рассчитывается по формуле:

```text
Награда = вес урожая × цена за кг × множитель мутации
```

Итоговая награда округляется до целого числа монет.

### Расширение фермы

Новая грядка позволяет одновременно выращивать больше культур.

- При регистрации игрок получает **8 слотов**.
- Первый дополнительный слот (№9) стоит **5 000 монет**.
- Цена каждого следующего слота увеличивается в 3 раза.
- Максимальное количество слотов в текущей конфигурации — **16**.

Формула цены следующего слота:

```text
Цена = 5 000 × 3^(номер слота − 9)
```

### Экономика и награды

Новый игрок получает **1 000 монет**.

Основной источник дохода — продажа собранного урожая. Монеты используются для покупки семян и расширения фермы.

Также доступна ежедневная награда. Получить её можно после прохождения 24-часового интервала с предыдущего получения:

- при балансе менее 10 000 монет начисляется 1 000 монет;
- при балансе от 10 000 монет начисляется 10% текущего баланса.

### Рейтинги и профиль

В игре предусмотрены два рейтинга:

- **По монетам** — игроки с наибольшим текущим балансом.
- **По лучшему урожаю** — игроки с самой большой наградой за один сбор.

Команда `/me` показывает персональную информацию: ник, Telegram username, ID, лучший сбор и вес лучшего урожая.

## 📋 Команды бота

| Команда | Назначение | Доступ |
|---|---|---|
| `/start` | Регистрация и приветствие | Все |
| `/menu` | Главное меню | Все |
| `/farm` | Открыть ферму | Все |
| `/help` | Справка по игре | Все |
| `/top` | Открыть рейтинги | Все |
| `/daily` | Получить ежедневную награду | Все |
| `/setnick <ник>` | Изменить игровой ник | Все |
| `/me` | Посмотреть профиль и статистику | Все |
| `/give_admin <ID> <сумма>` | Изменить баланс игрока | Администратор |
| `/backup` | Отправить резервную копию базы | Администратор |
| `/restore` | Восстановить базу из JSON-файла | Администратор |

Для `/restore` администратор должен ответить этой командой на сообщение с JSON-файлом резервной копии.

Основное взаимодействие с игрой происходит через inline-кнопки Telegram. Команды служат быстрым способом открыть нужный раздел или выполнить действие.

### Основные части

- `src/index.js` — точка входа: создание бота, регистрация команд и callback-обработчиков, запуск HTTP-сервера.
- `src/handlers/commands/` — обработчики Telegram-команд.
- `src/handlers/callback/` — обработчики нажатий inline-кнопок.
- `src/service/config.js` — игровые параметры: культуры, мутации, стартовый баланс и настройки слотов.
- `src/service/db.js` — чтение, изменение и сохранение данных игроков.
- `src/service/logic/` — игровая логика: посадка, сбор, мутации, расширение фермы, время, рейтинги и ежедневная награда.
- `src/utils/` — клавиатуры, тексты сообщений, безопасное редактирование сообщений и проверка администратора.

Игровая логика вынесена отдельно от Telegram-обработчиков. Это упрощает изменение механик без необходимости переписывать интерфейс бота.

## 🚀 Установка и запуск

### Требования

- Node.js 18.x
- npm
- Telegram Bot Token, полученный через [@BotFather](https://t.me/BotFather)

### 1. Клонирование репозитория

```bash
git clone https://github.com/Yakov-hub-python/FarmTycoon.git
cd FarmTycoon
```

### 2. Установка зависимостей

```bash
npm install
```

### 3. Настройка окружения

Создай файл `.env` на основе `.env.example`:

```env
BOT_TOKEN=YOUR_BOT_TOKEN
ADMIN_ID=YOUR_TELEGRAM_ID
PORT=8000
DB_PATH=database.json
```

Заполни `BOT_TOKEN` и `ADMIN_ID` своими значениями.

### 4. Запуск

Обычный запуск:

```bash
npm start
```

Режим разработки с автоматическим перезапуском при изменении файлов:

```bash
npm run dev
```

После запуска бот начнёт принимать обновления Telegram. HTTP-сервер также поднимется на порту, заданном через `PORT` (по умолчанию — `10000`).

## ⚙️ Переменные окружения

| Переменная | Обязательная | Значение по умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | Да | — | Токен Telegram-бота |
| `ADMIN_ID` | Нет | Пустая строка | Telegram ID администратора |
| `PORT` | Нет | `10000` | Порт HTTP-сервера |
| `DB_PATH` | Нет | `database.json` | Путь к JSON-файлу базы |

`BOT_TOKEN` проверяется при загрузке конфигурации. Без него приложение не запустится.

**Не публикуй `.env` и не добавляй токен бота в Git.** Для этого `.env` уже указан в `.gitignore`.

## 💾 Хранение данных и резервное копирование

Данные игроков хранятся в JSON-файле. Для каждого пользователя сохраняются:

- Telegram ID, username и игровой ник;
- баланс монет;
- список слотов и информация о посаженных культурах;
- время последнего получения ежедневной награды;
- статистика лучшего сбора.

При первом обращении игрок автоматически получает стартовый профиль.

Модуль базы данных использует очередь операций для последовательной записи и атомарную замену файла через временный файл. Если JSON повреждён, модуль пытается отложить его как `.corrupt` и возвращает пустую базу.

### Резервное копирование

- `/backup` отправляет администратору текущий JSON-файл.
- `/restore` загружает JSON из ответа на сообщение с файлом.
- Перед восстановлением текущая база копируется в файл с суффиксом `.before_restore`.

Резервные копии рекомендуется хранить отдельно от сервера, на котором работает бот.

## ☁️ Развёртывание

Приложение содержит HTTP-сервер, который отвечает текстом `Бот работает!`. Это позволяет использовать платформы, ожидающие HTTP-порт у веб-сервиса.

Для развёртывания на Render:

1. Создай Web Service и подключи GitHub-репозиторий.
2. Укажи среду Node.
3. Build Command: `npm install`.
4. Start Command: `npm start`.
5. Добавь `BOT_TOKEN`, `ADMIN_ID`, `PORT` и при необходимости `DB_PATH` в Environment Variables.

**Важно о файловом хранилище:** локальный JSON-файл не следует считать надёжным постоянным хранилищем на хостинге с эфемерной файловой системой. При перезапуске или новом деплое данные могут потеряться, если платформа не предоставляет подключённый persistent disk. Для сохранности данных настрой постоянный диск или перенеси хранение во внешнюю базу данных.

## 🧑‍💻 Разработка

В `package.json` определены команды:

```bash
npm start   # запуск приложения
npm run dev # запуск с Node.js watch mode
```

Отдельный автоматизированный набор тестов и команда `npm test` в текущем `package.json` не настроены.

При изменении игровых механик основные параметры следует проверять в `src/service/config.js`, а соответствующие алгоритмы — в `src/service/logic/`.
