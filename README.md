# 🌾 FarmTycoon

Telegram-бот в жанре idle-ферма. Игрок выращивает культуры, ловит мутации, прокачивает лабораторию и соревнуется в рейтингах.

## 🎮 Основные механики
- **Культуры:** 13 видов (от пшеницы за 15 сек до ананаса за 4 часа).
- **Мутации:** случайный множитель к награде (серебро ×1.75, золото ×4.5).
- **Погода:** глобальный цикл смены каждые 2 часа. Влияет на скорость роста и цену продажи.
- **Лаборатория (/lab):** 4 ветки прокачки (генетика, селекция, агрономия, земля) с кулдаунами.
- **Ферма:** от 8 стартовых до 20 слотов (через покупку или лабораторию).
- **Социальное:** VIP (+20% к доходу), реферальная система, рейтинги.

## 🛠 Стек технологий
- **Среда:** Node.js 18+
- **Фреймворк:** Telegraf 4
- **Хранение:** Локальный JSON-файл (с мьютексом и атомарной записью)
- **Деплой:** Render (Web Service)

## 🚀 Локальный запуск

1. **Клонируй репозиторий:**
   ~~~bash
   git clone https://github.com/Yakov-hub-python/FarmTycoon.git
   cd FarmTycoon
   ~~~

2. **Установи зависимости:**
   ~~~bash
   npm install
   ~~~

3. **Настрой окружение:**
   Создай файл `.env` по примеру `.env.example`:
   ~~~env
   BOT_TOKEN=твой_токен_от_BotFather
   ADMIN_ID=твой_telegram_id
   PORT=10000
   DB_PATH=database.json
   ~~~

4. **Запусти:**
   ~~~bash
   npm run dev   # с авто-перезагрузкой
   # или
   npm start     # обычный запуск
   ~~~

## 🗄 Хранение данных и БД
База данных — это один JSON-файл (`database.json`).
- **Атомарная запись:** данные пишутся во временный `.tmp` файл, который затем переименовывается. Это защищает от повреждения БД при сбое.
- **Мьютекс:** все операции чтения/записи выстроены в очередь (`Promise chain`), чтобы параллельные запросы не затирали данные друг друга.
- **Миграции:** в `db.js` (функция `normalizeUser`) при каждом входе проверяется наличие новых полей (например, `upgrades`). Если их нет — они создаются с дефолтными значениями.

### ⚠️ Важно для хостинга (Render)
На бесплатном тарифе Render **файловая система эфемерная**. При каждом деплое или перезапуске контейнера файл `database.json` **удаляется** и создаётся заново.
- Для сохранения прогресса используй **Persistent Disk** (платная опция Render) или встроенную команду `/backup` для ручного сохранения базы в Telegram.

## 🛡 Админ-команды
Доступны только пользователю с `ADMIN_ID` в `.env`:
- `/giveall <vip|coin> <amount>` — выдать VIP или монеты **всем** игрокам. Без подтверждения, выполняется сразу.
- `/backup` — отправить текущий JSON-файл базы в чат.
- *(Опционально)* `/restore` — восстановить базу из прикреплённого файла (если реализовано).
